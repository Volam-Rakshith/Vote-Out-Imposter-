# Vote Out Imposter — User Guide

Everything you need to run a game night. No accounts, no installs, no internet
(for One Mobile mode).

## Starting

1. Open the site and tap the **Game** tab (top right on desktop, bottom bar on
   mobile).
2. Choose a mode:
   - **One Mobile** — one device passed between players, works anywhere.
   - **Multiple Devices** — everyone plays on their own phone/laptop (needs
     the online service to be configured by the site owner; the game tells
     you if it isn't).
3. Want the details first? **Full rules** and **Settings** are linked on the
   same screen.

## Setting up a game (One Mobile)

- **Players** — add between 3 and 20. Type names, drag rows (or use the arrow
  buttons) to reorder, remove with the bin button. Recent players are
  remembered on your device for quick re-adds (each entry can be removed;
  clear-all asks for confirmation).
- **Imposters** — 1, 2, 3, 4, a custom number, or random. Turn on **Chaos
  Mode** for the five special variants (Everyone Is Imposter, No Imposter,
  Random Count, Custom Count, No Hints).
- **Secret words** — choose a difficulty and any combination of the 28
  categories. The screen always shows how many words are in play and warns
  before you pick an empty combination.
- **Match** — rounds (1/3/5/custom up to 20), discussion and voting timers,
  and whether eliminated imposters get a word-guessing chance. Turn on the
  **Speaking timer (per player)** for talking-stick mode: players speak in
  roster order, X seconds each (5–120s), and each player's phone vibrates
  when their turn starts. Voting begins automatically after the last speaker.
- **Audio** — music and sound effects have separate on/off switches and volume
  sliders, saved on this device.
- The **Start game** button lists every remaining problem — it never starts
  with an invalid setup.

Your whole setup (players + settings) is remembered for next time.

## Playing on one device

- **Role reveal:** the screen says whose turn it is. Pass the device to them;
  they tap *"I'm … — show my role"*, see their card alone, then tap *"Hide &
  pass"*. Repeat for everyone. The screen reminds everyone when it is private.
  Imposters don't get the word — they get a red **related-word hint** pill on
  their card (unless the No Hints chaos variant is on, in which case they get
  nothing at all).
- **Discussion:** talk about the word without saying it. A countdown runs if a
  timer was set (ticking sounds in the last 10 seconds — also shown visually).
  Anyone can tap **Start the vote** when the group is ready. With the speaking
  timer on, the screen shows whose turn it is with a per-player countdown; the
  device buzzes on turn changes, and voting starts by itself after the last
  speaker.
- **Voting:** the device is passed to each player in turn; each picks a player
  and confirms. Already-eliminated players don't vote and can't be picked.
  Totals are hidden until everyone has voted.
- **Results:** the tally appears, the eliminated player's role is revealed and
  the game continues to the next cycle (or ends).
- **Imposter guess:** if enabled, the imposter who was just voted out gets
  the device privately for **one last guess** — a correct guess steals the
  win instantly, even if they were the last imposter.
- **Between rounds:** the round result shows the word, the imposter's hint,
  all roles, guesses and the running session score.

**Refreshed by accident?** The game is saved. Return to the game home screen
and Resume — the
screen returns in a neutral state (no card left open). You can also Restart
(discard + new setup) or Abandon.

**After the match:** **Play Again** reuses the exact same players, order and
settings with fresh roles and words — ideal for leagues. **New game** opens
setup. Local stats accumulate on the device (Settings shows and clears them).

## Playing online (Multiple Devices)

1. The **host** opens Multiple Devices, enters a name and taps **Create
   room**. A 6-character room code appears with **Copy code**, **Copy invite
   link** and **Share** buttons.
2. Everyone else opens the invite link (or enters the code and a name) and
   joins. The lobby shows who is in, who is host and who is online.
3. The host configures settings in the lobby (players see the same options).
4. Host taps **Start game** — everyone's device privately shows their role.
5. From here the flow matches the rules: discussion → private voting on each
   device → live results → next round. Timers are driven by the server, so
   everyone agrees on them.
6. At the end, the host can **Play Again** for the whole room or exit.

**Connection trouble?** The game polls and reconnects automatically; a banner
shows the status. Refreshing keeps your seat via the saved session token (per
browser profile). If the host disappears, host rights transfer automatically
to the earliest-joined connected player after a short grace period.

## Good-faith play notes

- One Mobile hides roles behind taps — don't peek at other people's cards.
- Online, having a second device lets someone join twice; the room code is
  the only gate. Play with people you trust, like any party game.
